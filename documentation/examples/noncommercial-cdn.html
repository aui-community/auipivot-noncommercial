비상업용 CDN으로 피벗 만들기

판매 지점과 차종별 매출액을 색상별로 집계합니다. 오른쪽 필드 패널에서 필드를 끌어 분석 기준을 바꾸어 보세요.

비상업용 목적의 localhost 또는 127.0.0.1 웹 서버에서 실행합니다. CDN 파일을 불러올 때 인터넷 연결이 필요합니다.

localhost, 127.0.0.1 외의 접속 도메인이나 IP에서는 30일 평가판을 제공합니다. 정품과 동일한 기능으로 사전 평가, 적합성 검토(PoC), 테스트에 사용할 수 있습니다. 외부 서버에서 평가할 때는 CDN 경로를 내려받은 평가판 파일 경로로 바꾸세요.
