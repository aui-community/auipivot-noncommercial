1. AUIPivot 소개 및 사용 방법

1.1 AUIPivot이란?

AUIPivot은 다차원 집계, 그룹화, 교차 분석을 웹에서 제공하는 JavaScript 피벗 컴포넌트입니다.
원본 데이터를 행, 열, 값, 필터로 구성하여 대화형 보고서를 만듭니다.

  • 복잡한 보고서나 통계 데이터를 실시간으로 집계하고 분석합니다.
  • 엑셀(Excel) 피벗 테이블과 비슷한 화면을 제공합니다.
  • 사용자가 필드를 끌어 놓아 직접 다차원 분석을 구성할 수 있습니다.

1.3 지원 개발 환경

순수 JavaScript 컴포넌트이므로 다음 환경에서 사용할 수 있습니다.

  • 순수 JavaScript(Vanilla JS)
  • jQuery
  • React, Vue: 전용 서브 컴포넌트를 제공합니다. React, Vue 및 TypeScript에서 사용하기를 참고하십시오.

1.4 AUIPivot 사용 방법

AUIPivot은 독립적으로 실행되는 JavaScript 피벗 컴포넌트입니다.
제공받은 다음 파일을 배치하고 HTML에 연결합니다.

파일 역할
AUIPivot_style.css 피벗 화면 스타일. CSS가 참조하는 images 폴더를 함께 배치합니다.
AUIPivotLicense.js 사용 권한. 엔진보다 먼저 연결합니다.
messages/AUIPivot.messages.kr.js 화면 언어 파일. 엔진보다 먼저 연결합니다.
AUIPivot.js 피벗 엔진. 한 번만 연결합니다.

AUIPivotLicense.js와 언어 파일은 엔진보다 먼저 연결해야 합니다.
아래 예제는 한국어 화면이며, 상대 경로는 실제 설치 위치에 맞춥니다. 


<!-- 피벗의 화면 스타일과 이미지 폴더를 함께 배치합니다. -->
<link rel="stylesheet" href="./AUIPivot/AUIPivot_style.css" />
<!-- 사용 권한과 화면 언어를 먼저 설정합니다. -->
<script src="./AUIPivot/AUIPivotLicense.js"></script>
<script src="./AUIPivot/messages/AUIPivot.messages.kr.js"></script>
<!-- 피벗 엔진은 한 번만 로드합니다. -->
<script src="./AUIPivot/AUIPivot.js"></script>

피벗은 AUIPivot.create()로 만들고, 원본 데이터는 AUIPivot.setGridData()로 넣습니다.
실제 동작은 Quick Start에서 확인할 수 있습니다.

비상업용 버전의 CDN으로 시작하기

로컬 환경에서 무료로 시작하려면 비상업용 CDN 안내를 참고하세요. 데이터를 포함한 HTML 예제 하나로 피벗 보고서를 실행할 수 있습니다.
라이브러리와 프레임워크 샘플은 비상업용 GitHub 저장소에서도 내려받을 수 있습니다.

localhost, 127.0.0.1 외의 접속 도메인이나 IP에서는 30일 평가판을 제공합니다.
정품과 동일한 기능으로 사전 평가, 적합성 검토(PoC), 테스트에 사용할 수 있습니다. 평가판 사용 안내를 확인하세요.

1.6 일반 JS 샘플 실행 방법

  1. 제품 패키지의 압축을 푼 뒤 라이선스가 허용하는 웹 서버에 배치합니다. 비상업용 버전은 localhost 또는 127.0.0.1에서 실행합니다.
  2. /samples 또는 /documentation 폴더의 index.html을 브라우저로 엽니다.
  3. AUIPivot 샘플 기능을 바로 확인하고 테스트할 수 있습니다.
