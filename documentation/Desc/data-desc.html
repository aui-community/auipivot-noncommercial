2. AUIPivot 데이터 바인딩 및 피벗 그리드의 이해에 대하여

2.1 AUIPivot과 OLAP 개념

AUIPivot은 데이터를 여러 관점(차원)에서 나누어 분석하는 OLAP(On-Line Analytical Processing) 도구입니다.
원본 데이터(source data)만 넣으면 지역별, 월별처럼 원하는 기준으로 집계한 결과를 바로 볼 수 있습니다.

2.2 차원의 개념: Rows, Columns, Values, Filters

AUIPivot은 다음 네 가지 차원으로 피벗 큐브(pivot cube)를 구성합니다.

차원 역할 예
행 (Rows) 데이터를 세로 방향으로 묶는 기준 지역, 영업 담당자
열 (Columns) 데이터를 가로 방향으로 나누는 기준 반기, 분기, 월
값 (Values) 합계, 평균 등을 계산할 숫자 필드 판매 금액
필터 (Filters) 조건에 따라 포함하거나 제외할 기준 필드 색상

피벗 큐브 = 원본 데이터 + 차원 정보(행, 열, 값, 필터)

2.3 피벗 필드 정의 예시

네 차원에 사용할 필드는 각각의 메소드로 지정합니다.

// 행 필드
AUIPivot.setRowFields(myPivotID, ["REGION", "NAME", "MODEL"]);
// 열 필드
AUIPivot.setColumnFields(myPivotID, ["DATE_HALF", "DATE_QTR", "DATE_MONTH"]);
// 값 필드
AUIPivot.setValueFields(myPivotID, [{ "dataField": "TOTAL", "operation": "SUM" }]);
// 필터 필드
AUIPivot.setFilterFields(myPivotID, ["COLOR"]);

관련 API: setRowFields, setColumnFields, setValueFields, setFilterFields

2.4 원본 데이터 구조 (Raw Data)

AUIPivot은 객체를 요소로 갖는 1차원 배열, 즉 Flat JSON Array를 입력으로 받습니다.
객체의 키가 필드명이 되며 행, 열, 값, 필터에 이 필드명을 지정합니다. 

[
  { "category": "전자", "region": "서울", "month": "2024-01", "sales": 120000 },
  { "category": "전자", "region": "부산", "month": "2024-01", "sales": 80000 },
  { "category": "가전", "region": "서울", "month": "2024-01", "sales": 65000 }
]

2.5 피벗 원본 데이터 삽입 예시

서버에서 받은 원본 데이터를 setGridData()로 넣으면 지정한 필드 설정으로 피벗을 계산합니다. 

// 원본 데이터 요청
fetch("./data/sales_data.json")
  .then(res => res.json())
  .then(data => {
    // 피벗 그리드에 원본 데이터 삽입
	AUIPivot.setGridData(myPivotID, data);
});

2.6 요약

개념 설명
원본 데이터 분석 대상이 되는 JSON 배열 형태 데이터
행 세로 방향 그룹 기준
열 가로 방향 분할 기준
값 합계, 평균, 개수 등을 계산할 대상 필드
필터 조건 필터링용 기준 필드

AUIPivot은 원본 데이터와 피벗 정의만으로 분석 화면을 제공합니다.
