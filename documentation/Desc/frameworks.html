9. React, Vue 및 TypeScript에서 사용하기

AUIPivot 서브 컴포넌트(래퍼)는 React와 Vue의 생성 및 해제 시점에 맞춰 피벗을 관리합니다.
속성을 전달해 컴포넌트를 배치하고, ref로 행, 열, 값 필드와 데이터를 설정합니다.

JavaScript와 TypeScript용 컴포넌트를 각각 제공합니다. 사용 환경에 맞는 예제를 선택하십시오.
Vue 예제는 Vue 3의 script setup을 기준으로 작성했습니다.

9.1 파일 준비9.2 React 9.3 Vue9.4 서브 컴포넌트 속성

9.1 파일 준비와 공통 사용 흐름

제품 패키지의 샘플 프로젝트에서 시작하거나, 서브 컴포넌트와 제품 파일을 기존 프로젝트에 배치합니다.
실행 명령은 Vue, React 샘플 실행 방법을 참고하십시오.

  • React JavaScript: samples-React.js의 src/static/AUIPivot-React/AUIPivotReact.jsx
  • React TypeScript: samples-React.tsx의 src/static/AUIPivot-React.tsx/AUIPivotReact.tsx
  • Vue JavaScript: samples-Vue.js의 src/static/AUIPivot-Vue/AUIPivot.vue
  • Vue TypeScript: samples-Vue.ts의 src/static/AUIPivot-Vue/AUIPivotT.vue

위 경로는 샘플 내부의 경로입니다. 패키지 루트의 AUIPivot-React/, AUIPivot-Vue/에도 서브 컴포넌트를 제공합니다.
실제 배치한 위치에 맞춰 import 경로를 지정하십시오.

  1. 제품 배포본의 AUIPivot.js, 접속 환경에 맞는 AUIPivotLicense.js, AUIPivot_style.css, 해당 CSS가 참조하는 images/와 messages/AUIPivot.messages.kr.js를 준비합니다.
  2. 래퍼 상단의 엔진, 라이선스, 메시지 및 CSS import 경로를 확인합니다. 샘플에서는 ../AUIPivot/를 사용합니다.
    파일 위치는 프로젝트에 맞게 바꿀 수 있습니다. 래퍼가 엔진을 import하므로 같은 엔진을 script 태그로 중복 연결하지 않습니다.
  3. TypeScript 프로젝트에는 aui-pivot를 설치합니다.
    이 패키지는 타입과 EventKind enum을 제공하며, 실행 엔진, 라이선스, CSS 및 서브 컴포넌트는 포함하지 않습니다.
  4. 컴포넌트를 배치하고, 마운트 후 ref로 필드를 설정한 다음 setGridData()로 데이터를 입력합니다. 
npm install aui-pivot@latest

공식 TypeScript 샘플은 "aui-pivot": "latest"로 의존성을 선언합니다.
npm ci는 잠금 파일의 버전을 설치하며, 최신 버전으로 갱신하려면 npm update aui-pivot을 실행합니다.

타입 패키지는 AUIPivot.js 2.7부터 지원합니다. 최신 타입에 선언된 API라도 사용 중인 엔진에서 지원하는지 확인하십시오.

React의 .jsx, .tsx와 Vue의 .vue는 해당 프레임워크의 빌드 도구로 처리합니다. 샘플 프로젝트에는 Vite 설정이 포함되어 있습니다.

엔진 속성과 래퍼 속성

layoutType, height, showPivotPanel 같은 엔진 속성은 pivotProps에 넣습니다. autoResize, resizeMode 같은 래퍼 속성은 컴포넌트에 직접 지정합니다.
엔진 속성의 전체 목록은 AUIPivot 속성에서 확인할 수 있습니다.

9.2 React에서 사용하기

함수 컴포넌트에서 useRef로 AUIPivot 서브 컴포넌트를 참조하고, useEffect에서 초기화합니다.

9.2.1 JavaScript 예제

파일 준비를 마친 샘플 프로젝트에서 사용할 수 있는 예제입니다. 아래 파일은 src/samples/Report.jsx에 둔다고 가정합니다.
샘플에 포함된 public/data/car_sales.json을 읽으며, 실제 배치 위치에 맞춰 경로를 바꾸십시오.

예제는 createOnMounted=false로 자동 생성을 끄고 init()에서 createPivotGrid()를 호출해 한 번 생성합니다. 행은 지점과 차종, 열은 색상, 값은 매출 합계입니다.
requestData()에서 자료를 읽은 후 setGridData()로 집계합니다. 

import { useEffect, useRef } from 'react';
import AUIPivot from '../static/AUIPivot-React/AUIPivotReact';

export default function Report() {
    const pivotProps = { height: 400 };
    const myPivot = useRef(null);
    // 시작점에서 피벗을 생성한 뒤 자동차 자료를 읽습니다.
    function init() {
        createPivotGrid();
        return requestData(`${import.meta.env.BASE_URL}data/car_sales.json`);
    }
    function createPivotGrid() {
        const pivot = myPivot.current;
        if (!pivot) return;
        pivot.create(pivotProps);
        pivot.setRowFields(['REGION', 'NAME']);
        pivot.setColumnFields(['COLOR']);
        pivot.setValueFields([{ dataField: 'TOTAL', operation: 'SUM' }]);
        pivot.bind('pivotComplete', event => console.log(event.type));
    }
    // 요청 도중 화면이 해제되면 결과를 사용하지 않습니다.
    function requestData(url) {
        let disposed = false;
        fetch(url).then(response => {
            if (!response.ok) throw new Error('자료 요청 실패');
            return response.json();
        }).then(data => {
            const pivot = myPivot.current;
            if (!disposed && pivot?.isCreated()) pivot.setGridData(data);
        }).catch(error => { if (!disposed) console.error(error); });
        return () => { disposed = true; };
    }
    useEffect(() => init(), []);
    return <AUIPivot ref={myPivot} createOnMounted={false}
        resizeMode="container" resizeDelayTime={100} />;
}

9.2.3 메소드 호출과 이벤트

myPivot.current의 메소드는 대상 피벗 ID를 자동으로 전달합니다. 전역 API와 달리 첫 번째 인수에 ID를 넣지 않습니다.
예를 들어 myPivot.current?.setGridData(data)로 호출합니다.

이벤트는 생성 후 bind()로 등록합니다. React 컴포넌트에 onCellClick 같은 JSX 속성을 붙여 등록하지 않습니다.
문자열 이벤트 이름이나 aui-pivot의 EventKind를 사용할 수 있습니다. 

import { EventKind } from 'aui-pivot';
import type { CellClickEvent } from 'aui-pivot';

// 생성된 피벗에서 클릭한 셀의 값을 확인합니다.
const pivot = myPivot.current;
const onCellClick = (event: CellClickEvent) => console.log(event.value);
pivot?.bind(EventKind.cellClick, onCellClick);
// 같은 피벗에서 이 처리기만 제거할 때 동일한 함수 참조를 전달합니다.
pivot?.unbind(EventKind.cellClick, onCellClick);

위 코드는 등록과 선택적 해제 방법을 함께 보여 줍니다. 실제 해제는 해당 기능을 종료할 때 실행하십시오.
unbind(이벤트명)은 그 이벤트의 모든 처리기를 제거하므로 다른 기능이 등록한 처리기도 해제할 수 있습니다.

pivotBegin, headerClick, contextMenu처럼 반환값이 있는 이벤트는 등록한 함수에서 그 값을 직접 반환하십시오.
비동기 함수의 Promise로 취소 여부나 메뉴 목록을 반환하지 않습니다.

9.2.4 생성과 해제 시점

  • createOnMounted의 기본값은 true입니다. 자동 생성 시에는 pivotProps를 전달하고, 마운트 후 필드와 데이터를 설정합니다.
    같은 피벗에 create()를 중복 호출하지 않습니다.
  • 컴포넌트가 해제되면 피벗과 크기 감지 작업도 정리됩니다. 부모에서 엔진의 destroy()를 중복 호출할 필요가 없습니다.
  • 비동기 응답이 화면 해제 후 도착할 수 있습니다. 예제처럼 요청별 정리 함수와 isCreated()로 늦은 응답을 처리하지 않도록 합니다.
  • 생성 후 pivotProps를 바꾸는 것만으로 엔진 속성이 갱신되지는 않습니다. setProp()와 refresh() 등 해당 API를 사용합니다.

Portal 등에서 자동 생성 시점을 한 프레임 늦추려면 waitPortalRendering=true를 사용합니다. 이는 탭 표시나 애니메이션 완료를 보장하지 않습니다.
수동 생성 예제에서는 화면이 표시된 뒤 create()를 호출하고, 이미 생성된 피벗은 resize()로 크기를 다시 맞춥니다.

서버 렌더링 환경에서는 엔진과 서브 컴포넌트를 클라이언트에서만 불러오십시오. DOM이 준비된 후 생성하는 절차가 필요합니다.
크기 설정은 크기 감지와 표시 시점을 참고하십시오.

9.3 Vue에서 사용하기

Vue 3의 script setup에서 템플릿 ref로 서브 컴포넌트를 참조하고, onMounted에서 초기화합니다.

9.3.1 JavaScript 예제

파일 준비를 마친 샘플 프로젝트에서 사용할 수 있는 예제입니다. 아래 파일은 src/samples/Report.vue에 둔다고 가정합니다.
샘플에 포함된 public/data/car_sales.json을 읽으며, 실제 배치 위치에 맞춰 경로를 바꾸십시오.

예제는 createOnMounted=false로 자동 생성을 끄고 init()에서 createPivotGrid()를 호출해 한 번 생성합니다. 행은 지점과 차종, 열은 색상, 값은 매출 합계입니다.
requestData()에서 자료를 읽은 후 setGridData()로 집계합니다. 

<script setup>

const pivotProps = { height: 400 };
const myPivot = ref(null);

function init() {

}
function createPivotGrid() {
    const pivot = myPivot.value;
    if (!pivot) return;
    pivot.create(pivotProps);
    pivot.setRowFields(['REGION', 'NAME']);
    pivot.setColumnFields(['COLOR']);
    pivot.setValueFields([{ dataField: 'TOTAL', operation: 'SUM' }]);
    pivot.bind('pivotComplete', event => console.log(event.type));
}
// 요청 도중 화면이 해제되면 결과를 사용하지 않습니다.
function requestData(url) {
    return fetch(url).then(response => {
        if (!response.ok) throw new Error('자료 요청 실패');
        return response.json();

        const pivot = myPivot.value;
        if (!disposed && pivot?.isCreated()) pivot.setGridData(data);

onMounted(init);

9.3.3 메소드 호출과 이벤트

myPivot.value의 메소드는 피벗 ID를 자동으로 전달합니다. myPivot.value?.setGridData(data)처럼 ID를 제외하고 호출하십시오.

템플릿 이벤트는 피벗 생성 시 연결됩니다. 다음 코드는 위 예제에 셀 클릭 처리를 추가하는 부분입니다.

<!-- 기존 AUIPivot 태그에 셀 클릭 처리기를 연결합니다. -->
<AUIPivot ref="myPivot" :createOnMounted="false" @cellClick="onCellClick" />

<script setup lang="ts">
import type { CellClickEvent } from 'aui-pivot';
// 기존 script setup 블록에 추가합니다.
function onCellClick(event: CellClickEvent) {
    console.log(event.value);
}
</script>

같은 이벤트를 템플릿과 bind() 양쪽에 중복 등록하지 마십시오.
생성 후 새로 등록할 때는 myPivot.value?.bind('cellClick', handler)를 사용하고, 선택적으로 해제할 때는 동일한 함수 참조를 unbind('cellClick', handler)에 전달합니다.

pivotBegin, headerClick, contextMenu는 처리기의 반환값을 사용합니다.
템플릿에 함수 하나를 연결하고 그 함수에서 값을 직접 반환하십시오. 각 이벤트의 취소 및 반환 규칙은 API 문서를 따릅니다.

9.3.4 생성과 해제 시점

  • createOnMounted의 기본값은 true입니다. 자동 생성 시에는 :pivotProps="pivotProps"를 전달하고, 부모의 onMounted에서 필드와 데이터를 설정합니다.
    이 경우 create()를 다시 호출하지 않습니다.
  • 컴포넌트가 해제되면 피벗과 크기 감지 작업도 정리됩니다. 예제는 onBeforeUnmount에서 요청 결과의 적용도 중지합니다.
  • Vue의 반응형 pivotProps를 바꾸는 것만으로 생성된 피벗이 갱신되지는 않습니다. setProp()와 refresh() 등 해당 API를 사용합니다.

KeepAlive와 resizeMode="container"를 함께 쓰면 비활성화 중에는 크기 관찰을 멈추고, 다시 활성화될 때 관찰을 재개합니다. 피벗과 기존 데이터는 유지됩니다.
window 모드에서는 창 크기가 바뀌지 않은 탭 전환을 자동 감지하지 않으므로 표시 후 resize()를 호출하십시오.

v-if로 만든 영역은 nextTick() 이후 실제 DOM이 연결되어 있는지 확인합니다. 전환 효과가 있다면 표시 전환이 끝난 시점에 resize()를 호출하십시오.
nextTick()만으로 애니메이션 완료가 보장되지는 않습니다.

Vue 컴포넌트에는 waitPortalRendering 속성이 없습니다.
서버 렌더링 환경에서는 엔진과 컴포넌트를 클라이언트에서만 불러오고, DOM이 준비된 뒤 생성하십시오.
자세한 크기 설정은 크기 감지와 표시 시점을 참고하십시오.

9.4 서브 컴포넌트 속성

다음은 React와 Vue 서브 컴포넌트에 직접 지정하는 속성입니다. 피벗 엔진의 속성은 pivotProps 또는 수동 생성 시 create()에 전달합니다.

속성 타입 기본값 지원 컴포넌트
autoResize boolean true React, Vue의 JavaScript 및 TypeScript
createOnMounted boolean true 네 컴포넌트 공통
name string 빈 문자열 네 컴포넌트 공통
pivotProps Props 객체 {} 네 컴포넌트 공통
resizeDelayTime number 300 (밀리초) 네 컴포넌트 공통
resizeMode "window" | "container" "window" 네 컴포넌트 공통
waitPortalRendering boolean false React JavaScript 및 TypeScript만 지원

9.4.1 autoResize

컴포넌트가 크기 변경을 감지해 피벗 크기를 자동으로 맞출지 지정합니다. 기본값은 true입니다.
false이면 자동 감지를 사용하지 않으며, 필요할 때 ref의 resize()를 직접 호출합니다.

9.4.2 createOnMounted

마운트 시 pivotProps로 피벗을 자동 생성합니다. 기본값은 true입니다. false이면 DOM이 준비된 후 ref의 create(pivotProps)를 호출하십시오.
행, 열, 값 설정과 데이터 입력은 생성 이후에 수행합니다.

9.4.3 name

피벗 영역의 DOM ID에 사용할 이름입니다. 기본값인 빈 문자열이면 이름을 자동 생성합니다.
명시한 경우 aui-pivot-wrap-이름 형태가 되므로 같은 화면에서 중복되지 않는 값을 사용하십시오. 생성 후 이름을 바꾸지 않습니다.
실제 피벗 ID는 ref의 getPID()로 확인할 수 있습니다.

9.4.4 pivotProps

자동 생성 시 사용할 피벗 엔진 속성입니다. 기본값은 빈 객체입니다. TypeScript에서는 aui-pivot의 Props로 선언합니다.
수동 생성에서는 이 객체를 create(pivotProps)에 직접 전달합니다. 

// 너비를 생략하면 부모 영역에 맞춥니다. 높이 단위는 픽셀입니다.
const pivotProps = {
    height: 400,
    layoutType: 'table',
    showPivotPanel: true
};

생성 후 객체 변경을 자동으로 반영하지 않습니다. setProp() 등 해당 속성의 적용 API를 사용하십시오.

9.4.5 resizeDelayTime

크기 변경을 감지한 뒤 자동 조정을 실행하기까지 기다리는 시간입니다. 기본값은 300밀리초입니다.
0 이상의 숫자를 지정하며, 연속 알림은 마지막 알림 기준으로 합칩니다. 수동 resize() 호출에는 이 대기 시간을 적용하지 않습니다.

9.4.6 resizeMode

autoResize=true일 때 감지 대상을 지정합니다. 기본값은 "window"입니다.

  • window: 브라우저 창의 resize 이벤트를 감지합니다.
  • container: ResizeObserver로 피벗 호스트 영역의 크기를 감지합니다.
    사이드바, 분할 화면, CSS 레이아웃처럼 창 크기가 그대로인 상태의 영역 변경에 사용합니다.

컨테이너 모드에서는 resizeDelayTime 이후 다음 화면 프레임에서 크기를 맞춥니다.
숨겨져 있거나 화면에서 해제된 영역, 크기가 같은 반복 알림은 처리하지 않습니다.
ResizeObserver를 지원하지 않는 환경에서는 창 resize 이벤트로 대체합니다. 

// React: 자동 생성과 부모 영역 크기 감지를 함께 사용합니다.
<AUIPivot ref={myPivot} pivotProps={pivotProps}
    resizeMode="container" resizeDelayTime={100} />
<!-- Vue: 숫자와 객체 속성은 바인딩으로 전달합니다. -->
<AUIPivot ref="myPivot" :pivotProps="pivotProps"
    resizeMode="container" :resizeDelayTime="100" />

9.4.7 waitPortalRendering

React에서 자동 생성을 한 프레임 늦춥니다. 기본값은 false이며 React JavaScript와 TypeScript만 지원합니다.
createOnMounted=true일 때 적용됩니다. 수동 create()에는 적용되지 않습니다.

이 설정은 Portal의 생성 시점을 조절하는 옵션입니다. 애니메이션이나 숨겨진 탭의 표시 완료까지 기다리는 설정은 아닙니다.

9.4.8 크기 설정과 표시 시점

width, height는 피벗 엔진의 숫자 속성입니다. 부모 너비에 맞추려면 width를 생략하십시오. width: "100%"와 같은 문자열을 넣지 않습니다.
부모 영역에는 실제 너비가 있어야 하며 Flex나 Grid 항목이 줄어들어야 할 때는 min-width: 0을 지정합니다.

일정한 높이가 필요하면 height에 픽셀 값을 지정합니다.
컨테이너 감지는 피벗의 데이터에 따른 자동 높이 정책을 바꾸거나 부모 높이를 항상 채우도록 강제하지 않습니다.

숨겨진 탭, 접힌 패널이나 이동 중인 모달은 표시된 후 크기를 맞추십시오.
컨테이너 모드는 영역이 다시 나타나면 재측정하며, 수동으로 제어할 때는 표시 전환이 끝난 뒤 resize()를 호출합니다.

래퍼 속성은 생성 전 설정을 기준으로 사용합니다. 생성 후 감지 방식을 바꾸어야 하면 새 설정으로 컴포넌트를 다시 마운트하십시오.
Vue의 KeepAlive 동작은 생성과 해제 시점을 참고하십시오.
