StaticUtils

AUIPivot 객체에서 바로 사용하는 정적 속성과 함수 목록입니다.

정적 속성과 함수는 피벗 생성 여부와 관계없이 사용할 수 있습니다.

Name Description
releaseDate
Type : Property   Version: 2.0

AUIPivot의 배포 날짜를 반환합니다.
문의나 오류 보고 시 사용 중인 AUIPivot의 배포 날짜를 확인하려면 이 속성을 사용합니다.

현재 사용하고 있는 AUIPivot의 배포 정보를 알고자 한다면 다음처럼 알 수 있습니다.


 alert(AUIPivot.releaseDate);
version
Type : Property   Version: 2.0

AUIPivot 버전 정보를 반환합니다.
문의나 오류 보고 시 사용 중인 AUIPivot의 버전을 확인하려면 이 속성을 사용합니다.

현재 사용하고 있는 AUIPivot의 버전 정보를 알고자 한다면 다음처럼 알 수 있습니다.


 alert(AUIPivot.version);
