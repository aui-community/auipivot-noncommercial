StaticUtils

AUIPivot 에서 사용 가능한 유틸성 정적(Static) 속성 및 함수 리스트입니다.

유틸성 정적(Static) 속성 및 함수는 AUIPivot 생성 여부와 관계 없이 어디서든 사용 가능합니다.

NameDescription
releaseDate
Type : Property   Version: 2.0

AUIPivot 의 배포 날짜를 반환합니다.

현재 사용하고 있는 AUIPivot 의 배포 정보를 알고자 한다면 다음처럼 알 수 있습니다.


 alert(AUIPivot.releaseDate);
version
Type : Property   Version: 2.0

AUIPivot 버전 정보를 반환합니다.

현재 사용하고 있는 AUIPivot 의 버전 정보를 알고자 한다면 다음처럼 알 수 있습니다.


 alert(AUIPivot.version);
