8. AUIPivot 속성, 메소드, 이벤트 설정에 대하여

AUIPivot은 피벗을 생성하고 속성, 메소드와 이벤트를 다루는 JavaScript 객체입니다.
피벗을 만들 때는 AUIPivot.create() 정적 함수를 사용합니다. 

// 피벗 속성을 설정합니다.
const pivotProps = {
    // 피벗 패널을 표시할 DIV의 id를 지정합니다.
    pivotPanelId : "#pivot_panel",
    // 행 필드를 표 형태로 출력합니다.
    layoutType : "table"
};

// id가 pivot_wrap인 DIV에 피벗을 생성합니다.
const myPivotID = AUIPivot.create("#pivot_wrap", pivotProps);

AUIPivot.create()는 지정한 DIV(예: #pivot_wrap)에 피벗을 하나 만들고, 다른 메소드에서 사용할 피벗 ID를 반환합니다.
두 번째 인자 pivotProps는 생성할 때 바꿀 속성을 key-value로 담은 객체이며 생략할 수 있습니다.

이벤트는 create()를 호출한 뒤 AUIPivot.bind()로 연결합니다.

// id가 pivot_wrap인 DIV에 피벗을 생성합니다.
const myPivotID = AUIPivot.create("#pivot_wrap", pivotProps);

// 셀을 클릭하면 이벤트 유형을 표시합니다.
AUIPivot.bind(myPivotID, "cellClick", function(event) {
    alert(event.type);
});

다음은 AUIPivot에서 설정할 수 있는 속성, 메소드, 이벤트와 정적 함수 목록입니다.

Type Description
Events

사용자 조작과 피벗 상태 변화를 처리하는 이벤트 목록입니다.
이벤트는 AUIPivot.bind()로 연결하며, 발생 조건과 전달되는 이벤트 정보, 반환값의 의미는 각 항목을 확인하십시오.

Methods

피벗을 만든 뒤 데이터, 필드 배치, 표시 상태 등을 제어하는 메소드 목록입니다.
대부분의 메소드는 create()가 반환한 피벗 ID(예: myPivotID)를 첫 번째 인자로 전달합니다.
각 항목에서 호출 목적과 매개변수, 반환값 및 사용 조건을 확인할 수 있습니다.

Properties

피벗을 생성할 때 pivotProps 객체로 지정하는 속성 목록입니다.
각 항목의 기본값과 적용 조건을 확인하여 필요한 기능을 설정하십시오.

StaticUtils

AUIPivot 객체에서 바로 사용하는 정적 속성과 함수 목록입니다.

정적 속성과 함수는 피벗 생성 여부와 관계없이 사용할 수 있습니다.
