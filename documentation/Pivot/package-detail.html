8. AUIPivot 속성, 메소드, 이벤트 설정에 대하여

AUIPivot 은 피벗을 생성하고, 속성, 메소드 및 이벤트를 처리할 수 있는 자바스크립트 객체입니다.

단일의 피벗 그리드를 생성하기 위해서는 다음과 같이 AUIPivot.create() 정적 함수를 사용합니다.

// 피봇 그리드 속성 설정
const pivotProps = {
    // 피벗 패널 사용을 위해 피벗 패널이 생성될 DIV 의 아이디를 지정함.
    pivotPanelId : "#pivot_panel",
    // 피벗 그리드 출력 방식 
    layoutType : "table"
};

// 실제로 #pivot_wrap 에 피벗 그리드 생성
const myPivotID = AUIPivot.create("#pivot_wrap", pivotProps);

AUIPivot.create() 는 피벗 그리드를 하나 생성하여 id가 pivot_wrap 로 정의된 Div 태그를 찾아 피벗 그리드를 출력합니다.

pivotProps 파라메터는 옵션 사항으로 피벗 생성 시 변경할 속성을 key-value 로 갖는 Object 입니다.

피벗의 이벤트를 핸들링 하기 위해서는 create() 정적 함수 호출 후에 이벤트를 바인딩하여 핸들링하십시오.

// 실제로 #pivot_wrap 에 피벗 그리드 생성
const myPivotID = AUIPivot.create("#pivot_wrap", pivotProps);

// 피벗 그리드 cellClick 이벤트 바인딩 
AUIPivot.bind(myPivotID, "cellClick", function(event) {
    // 이벤트 핸들링
    alert(event.type);
});

다음은 AUIPivot 의 설정 가능한 속성 및 이벤트, 메소드 리스트입니다.

TypeDescription
Events

AUIPivot 에서 송출되는 이벤트 리스트입니다.
Methods

AUIPivot 에서 호출 가능한 메소드 리스트입니다.
Properties

AUIPivot 에서 정의 가능한 속성 리스트입니다.
StaticUtils

AUIPivot 에서 사용 가능한 유틸성 정적(Static) 속성 및 함수 리스트입니다.

유틸성 정적(Static) 속성 및 함수는 AUIPivot 생성 여부와 관계 없이 어디서든 사용 가능합니다.
