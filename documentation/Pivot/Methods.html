Methods

AUIPivot 에서 호출 가능한 메소드 리스트입니다.

아래는 설정 예제 입니다. 

  AUIPivot.setColumnFields(myPivotID, ["DATE_HALF", "DATE_QTR", "DATE_MONTH"]);

모든 피벗 메소드는 create() 메소드 호출 시 사용한 pid 를 기본 파라메터로 삽입해야 합니다.

파라메터 첫번째 인자는 pid 입니다.(샘플 상 myPivotID 변수)

문서에서 pid 파라메터는 기본으로 설명에서 생략되었습니다.

즉, setColumnFields 메소드에 대한 설명으로 파라메터는 1개로 설명되지만 실제적으로 2개를 삽입해야 합니다.

첫번째 인자는 pid 이고, 설명된 fields 가 2번째 인자가 됩니다.

문서상에 정리된 파라메터를 실제 적용시 주의해 주십시오.

NameDescription
bind
Type : Method   Version: 1.0

피벗 그리드 이벤트를 핸들링하기 위해 이벤트를 바인딩하는 메소드입니다.

파라메터 설명

  • type : (String or Array) 바인딩하고자 하는 이벤트 유형
  • function : (Function) 이벤트 핸들러 함수

예를 들면 cellClick 이벤트를 핸들링하고 싶다면 다음과 같습니다.


 AUIPivot.bind(myPivotID, "cellClick", function( event ) {
       alert(event.value + " clicked");
       //alert(JSON.stringify(event));
 });

 // 복수의 이벤트를 한번에 핸들링 하기 (이벤트 유형을 배열로 설정)
 AUIPivot.bind(myPivotID, ["cellClick", "headerClick", "footerClick"], function( event ) {
       if(event.type === "cellClick") alert("You clicked cell : " + event.value);
       else if(event.type === "headerClick") alert("You clicked header : " + event.headerText);
 });
changeHeatmapColors
Type : Method   Version: 1.0

히트맵 출력을 사용한 경우(useHeatmap=true) 개별 필드, 연산자에 히트맵 스펙트럼 컬러를 변경하고, 업데이트 합니다.

파라메터 설명

  • dateField : (String) 필드명
  • operation : (String or null) 연산자명, 만약 null 지정 시 모든 연산자로 대체함.
  • colors : (Array) 히트맵으로 표현할 컬러 스펙트럼

 // 매출액(TOTAL) 이 "합계" 연산에 대하여 흰색~빨갱색 스펙트럼 변경
 AUIPivot.changeHeatmapColors(myPivotID, "TOTAL", "SUM",  ["#ffffff", "#ff0000"]);
 // 매출액(TOTAL) 이 모든 연산에 대하여 흰색~빨갱색 스펙트럼 변경
 AUIPivot.changeHeatmapColors(myPivotID, "TOTAL", null,  ["#ffffff", "#ff0000"]);

clearPivot
Type : Method   Version: 2.5.4

설정된 행, 열, 값, 필터의 모든 설정 및 원본 데이터(source data)를 초기화한 후 업데이트 합니다.

피벗 보고서 작성을 위해 삽입된 원본 데이터까지 초기화하므로 단순히 행, 열, 값 등의 피벗 설정만 초기화를 원한다면 clearPivotFieldsAll 메소드를 사용하십시오.

clearPivotFieldsAll
Type : Method   Version: 1.0

설정된 행, 열, 값, 필터의 모든 설정을 초기화합니다.

dateTypeField 를 지정했다면 dateTypeField 역시 해제 됩니다.

참고 : clearPivotFieldsAll 메소드는 피벗팅을 업데이트 하지 않습니다. 업데이트를 원하면 updatePivot 메소드를 사용하십시오.


  // 모든 필드 초기화
  AUIPivot.clearPivotFieldsAll(myPivotID);
  // 새로 피벗팅 업데이트
  AUIPivot.updatePivot(myPivotID);

createPivotPanel
Type : Method   Version: 1.0

생성된 피벗 그리드에 필드 패널을 추가합니다.

파라메터 설명

  • gridPID (String): 피벗 ID
  • props (Object, 선택): pivotPanelId, panelWidth, panelHeight 등의 패널 속성

Return : 없음

// HTML에 준비한 #panel 영역에 필드 패널을 표시합니다.
AUIPivot.createPivotPanel(myPivotID, {
    pivotPanelId: "#panel",
    panelWidth: 420,
    panelHeight: 460
});

외부 영역은 props.pivotPanelId로 지정합니다. 두 번째 인수에 문자열을 직접 전달하는 방식은 지원하지 않습니다. 영역을 생략하거나 null로 지정한 경우, 해당 DIV를 찾지 못한 경우에는 패널 영역을 자동 생성합니다.

패널이 이미 있거나 피벗 ID가 없으면 아무 작업도 하지 않습니다. 다른 설정으로 다시 만들려면 destroyPivotPanel로 먼저 제거합니다.
createSlicer
Type : Method   Version: 2.7

필드값을 버튼으로 선택하여 보고서를 필터링하는 슬라이서를 만듭니다.

파라메터 설명

  • container (String): 슬라이서를 표시할 HTML 요소의 CSS 선택자
  • options (Object): 다음 설정을 갖는 객체
    • dataField (String, 필수): 행, 열, 필터에 등록된 필드명
    • title (String): 제목. 생략하면 필드 별칭을 사용합니다.
    • columnCount (Number): 버튼 열 수. 1~20의 정수이며 기본값은 1입니다.
    • showSearch (Boolean): 검색창 표시 여부. 기본값은 true입니다.
    • movable, resizable (Boolean): 이동, 크기 조절 허용 여부. 각각 기본값은 true입니다.

Return : 슬라이서 ID. 피벗 ID가 없으면 undefined입니다. 같은 영역에 중복 생성하거나 옵션이 잘못되면 오류가 발생합니다.

// REGION이 행, 열, 필터에 등록되어 있고 #region 영역이 준비된 경우입니다.
const regionSlicer = AUIPivot.createSlicer(myPivotID, "#region", {
    dataField: "REGION",
    title: "판매 지점",
    columnCount: 2
});

원본 입력 전에도 생성할 수 있으며 데이터가 준비되면 버튼이 채워집니다. 선택, 배치와 저장 방법은 슬라이서 사용 안내를 참고하십시오.

Also See: getSlicerSelection | setSlicerSelection | destroySlicer | 관련 데모 보기

destroySlicer
Type : Method   Version: 2.7

슬라이서를 제거합니다. 표시 영역과 다른 자식 요소, 적용된 필터는 유지합니다.

exportToCsv
Type : Method   Version: 2.5.16

현재 피벗 결과를 CSV 파일로 내보냅니다.

파라메터 설명

  • exportProps (Object): 파일명 등의 내보내기 옵션

내보내기 공통 옵션 — exportToCsv, exportToPdf, exportToXlsx에서 사용합니다.

  • fileName (String): 파일명. 서버로 전송할 때도 파일명으로 전달됩니다.
  • beforeRequestCallback, afterRequestCallback (Function): 내보내기 전, 후에 호출할 함수
  • localControl (Boolean): 다운로드 대신 localControlFunc에 Blob을 전달할지 여부. 기본값은 false입니다.
  • localControlFunc (Function): localControl이 true일 때 작성한 파일의 Blob을 받는 함수
  • postToServer (Boolean): exportURL로 파일 데이터를 전송할지 여부. 기본값은 false입니다.

CSV의 progressBar (Boolean)는 진행률 표시 여부이며 기본값은 false입니다.

// 현재 보고서를 CSV로 저장합니다.
AUIPivot.exportToCsv(myPivotID, {fileName: "판매보고서"});
exportToPdf
Type : Method   Version: 2.5

현재 피벗 결과를 PDF 파일로 내보냅니다.

파라메터 설명

  • exportProps (Object): 내보내기 공통 옵션과 다음 PDF 옵션
    • fontPath (String, 필수): PDF에 사용할 글꼴 파일 URL
    • compress (Boolean): 압축 여부. 기본값은 false입니다.
    • isRowStyleFront (Boolean): 행 스타일을 열 스타일보다 우선할지 여부. 기본값은 true입니다.
    • headers, footers (Array): 표 위, 아래에 추가할 행. 각 객체는 text(문자열), height(픽셀 높이), style(스타일 객체)을 갖습니다. style에는 fontSize, textAlign, underline, background, color를 사용합니다.
// fontPath에 실제 사용할 글꼴 파일 경로를 지정합니다.
AUIPivot.exportToPdf(myPivotID, {
    fileName: "판매보고서",
    fontPath: "./pdfkit/jejugothic-regular.ttf"
});

셀 병합은 적용하지 않으며 행 높이는 동일하게 출력합니다. 최대 페이지 크기는 1682 × 2378mm(4A0)입니다. 사용 가능 여부는 isAvailabePdf로 확인합니다.
exportToXlsx
Type : Method   Version: 2.5.16

현재 피벗 결과를 엑셀(xlsx) 파일로 내보냅니다.

파라메터 설명

  • exportProps (Object): 내보내기 공통 옵션과 다음 엑셀 옵션
    • compress (Boolean): 압축 여부. 기본값은 false입니다.
    • exceptColumnFields (Array): 제외할 칼럼의 dataField 목록
    • exportWithStyle (Boolean): 글꼴, 색상 등의 스타일 포함 여부
    • fontFamily (String): 글꼴명. 기본값은 "맑은 고딕"입니다.
    • progressBar (Boolean): 진행률 표시 여부. 기본값은 false입니다.
    • sheetName (String): 시트 이름. 기본값은 "Sheet 1"입니다.
    • fixedColumnCount (Number): 엑셀에서 틀 고정할 열 수
    • headers, footers (Array): 표 위, 아래에 추가할 행. 각 객체는 text(문자열), height(픽셀 높이), style(스타일 객체)을 갖습니다. style에는 fontSize, textAlign, fontWeight, underline, background, color를 사용합니다.
// 파일명과 시트 이름을 지정해 저장합니다.
AUIPivot.exportToXlsx(myPivotID, {
    fileName: "판매보고서",
    sheetName: "지점별 매출"
});

getColumnInfoList
Type : Method   Version: 1.8

피벗 그리드에 출력된 칼럼 정보를 갖는 1차원 배열을 반환합니다.

만약 열(columns) 차원이 2개 이상으로 설정한 경우, 열 차원은 계층 구조를 이루게 됩니다. 이런 경우 이 메소드의 반환 값은 최하위 자식들의 정보만을 담은 배열입니다.

열 차원이 계층 구조가 아닌 경우, 이 반환값은 getColumnLayout() 메소드의 값과 같습니다.

Return : (Array) 현재 그리드 칼럼 레이아웃
getCustomValueOrders
Type : Method

setCustomValueOrders로 지정한 항목 순서를 반환합니다.

Return : (Array) {dataField, values} 객체 배열의 독립 사본. 설정이 없으면 [], 피벗 ID가 없으면 null입니다.

// REGION의 순서를 지정해 둔 경우의 조회 예입니다.
const orders = AUIPivot.getCustomValueOrders(myPivotID);
console.log(orders);
// [{dataField: "REGION", values: ["서울 지점", "부산 지점"]}]

등록한 순서만 반환하며 지정하지 않은 항목은 포함하지 않습니다. 사본을 수정해도 현재 설정은 바뀌지 않습니다.

Also See : setCustomValueOrders | getReportDefinition | 관련 데모 보기 — 업무 순서 비교

등록한 사용자 정의 집계의 ID, 버전, 표시 이름을 반환합니다.

registerCustomAggregator
Type : Method

직접 작성한 집계 방법을 등록합니다. 반환된 ID를 setValueFields의 operation에 지정하면 셀, 소계, 총계에 사용할 수 있습니다.

파라메터 설명

  • definition (Object): 다음 속성과 콜백을 갖는 집계 정의
  • id (String, 필수): 영문 대문자로 시작하는 1~64자의 대문자, 숫자, 밑줄. 내장 연산이나 같은 피벗에 등록한 ID와 중복될 수 없습니다.
  • version (Number, 필수): 계산 정의의 버전인 양의 정수. 보고서 복원 시 같은 ID와 버전을 등록해야 합니다.
  • labelText (String, 필수): 패널의 연산 목록에 표시할 이름. 빈 문자열은 사용할 수 없습니다.
  • defaultOptions (Object, 선택): 기본 옵션. 값 필드의 aggregatorOptions가 있으면 그 객체로 대체하며 병합하지 않습니다. 둘 다 없으면 빈 객체를 사용합니다. 옵션은 JSON으로 저장 가능해야 하며 콜백에서 수정할 수 없습니다.
  • validateOptions(options, context)
    선택    : 옵션을 검사합니다. true 또는 반환 생략은 통과, false 또는 오류는 거부입니다. context는 dataField, operation, requireField(name)을 제공합니다. requireField로 보조 필드를 선언하며 실제 필드 존재 여부는 원본을 확인할 때 검사합니다. 기본 옵션의 등록 검사에서는 dataField가 빈 문자열입니다. 설정, 재계산 중 여러 번 호출될 수 있습니다.
  • create(context)
    필수    : 매번 새로 만든 수정 가능한 누적 객체(state)를 반환합니다. 여러 셀이 객체 하나를 공유하면 안 됩니다.
  • accumulate(state, value, context)
    필수    : 원본 한 건의 dataField 값을 state에 반영합니다. value는 자동으로 숫자 변환되지 않습니다. state를 직접 수정하며 반환값은 없습니다.
  • merge(target, source, context)
    필수    : 두 누적 객체를 합칩니다. target만 수정하고 source는 읽기만 합니다. 반환값은 없으며 병합 순서가 달라도 계산 의미가 같아야 합니다.
  • finalize(state, context)
    필수    : state를 수정하지 않고 최종 숫자 또는 null을 반환합니다. NaN과 Infinity도 빈 값으로 표시합니다. 서식 문자열은 반환하지 않습니다.

계산 콜백의 읽기 전용 context에는 dataField, operation, options, getValue(name)가 전달됩니다. getValue는 accumulate 안에서만 같은 기록의 원본 필드나 등록한 파생 필드를 읽을 수 있습니다. 다른 계산 콜백에서 호출하면 오류이며 requireField는 검증 콜백에서만 사용합니다.

Return : 등록한 연산 ID. 등록 실패 시 오류가 발생합니다.

// 가격이 300만원 이상인 판매기록 수를 계산합니다.
const operation = AUIPivot.registerCustomAggregator(myPivotID, {
    id: "HIGH_PRICE_COUNT", version: 1, labelText: "300만원 이상 기록 수",
    create() {
        // 계산 영역마다 별도 누적 객체를 만듭니다.
        return {count: 0};
    },
    accumulate(state, value) {
        // 숫자인 가격 중 조건을 만족하는 기록만 셉니다.
        if (typeof value === "number" && Number.isFinite(value) && value >= 3000000) {
            state.count += 1;
        }
    },
    merge(target, source) {
        // 소계와 총계에는 각 영역의 기록 수를 더합니다.
        target.count += source.count;
    },
    finalize(state) {
        // 누적 객체를 바꾸지 않고 결과만 반환합니다.
        return state.count;
    }
});
AUIPivot.setValueFields(myPivotID, [{dataField: "PRICE", operation: operation}]);
AUIPivot.updatePivot(myPivotID);

콜백은 Promise를 반환하지 않는 동기 함수로 작성합니다. 등록은 피벗별이며 같은 ID를 다시 등록하여 교체할 수 없습니다. 보고서 복원 전에는 같은 ID와 버전의 계산 정의를 등록합니다.

옵션을 사용하는 가중 평균의 작성 과정은 사용자 정의 집계 안내를 참고하십시오.

Type : Method   Version: 2.7

피벗 필드 패널의 그룹과 필드 표시 순서를 지정합니다. 현재 구성을 전체 교체하며 즉시 표시합니다.

파라메터 설명

  • labelText (String): 그룹 제목
  • children (Array): 그룹 안의 필드 또는 하위 그룹
  • expanded (Boolean): 그룹의 초기 펼침 여부. 생략하면 true

배열 순서대로 표시합니다. 미지정 필드는 마지막에 기존 setFieldOrder() 순서로 표시합니다. 그룹을 해제하면 기존 평면 순서로 돌아갑니다.

그룹 제목을 마우스나 터치로 끌어 행, 열, 값, 필터에 놓으면 하위 필드를 순서대로 배치합니다. 접힌 하위 그룹도 포함합니다. 같은 차원에 있는 필드는 재사용하며, 값 영역에서는 같은 연산의 항목을 재사용합니다. 새 값 항목은 숫자 필드에 SUM, 그 외 필드에 COUNT를 사용합니다. 제목을 누르면 접거나 펼칩니다.

자료 입력 전에도 설정할 수 있습니다. 현재 없는 필드와 제외 필드, 표시할 자식이 없는 그룹은 생략합니다. 자료가 바뀌어도 같은 그룹의 접힘 상태를 유지하며, 이 메소드를 다시 호출하면 초기 펼침 상태로 돌아갑니다.

필드명이나 그룹 ID의 중복, 순환 구조, 잘못된 타입이나 객체 항목은 Error를 발생시키고 기존 설정을 유지합니다. 반환값은 없습니다.

// 그룹 순서와 그룹 안의 필드 순서를 배열로 지정합니다.
AUIPivot.setFieldLayout(myPivotID, [
    { groupId: "vehicle", labelText: "차량 정보", children: [
        { dataField: "NAME" }, { dataField: "MODEL" }
    ] },
    { groupId: "sales", labelText: "판매 정보", expanded: false, children: [
        { dataField: "COUNT" }, { dataField: "TOTAL" }
    ] }
]);

이 메소드 호출은 집계와 행, 열, 값, 필터 배치를 바꾸지 않습니다. 그룹 구성은 보고서 저장 대상이 아니며 보고서 복원 후에도 유지합니다. 별도로 저장하려면 getFieldLayout()을 사용합니다.

setVisualAnalytics
Type : Method

값 필드에 히트맵이나 데이터바를 표시합니다.

파라메터 설명

  • definitions (Array): 다음 설정 객체의 배열
    • dataField, operation: 시각화를 적용할 값 필드와 연산
    • heatmap, dataBar: 색상, 막대 설정 객체. false이면 해당 표시를 끕니다.
    • scope: heatmap 또는 dataBar 안에 지정할 비교 범위. GLOBAL은 같은 값 필드 전체, ROW는 같은 행, COLUMN은 같은 열이며 기본값은 GLOBAL입니다.
    • summaryColumns, summaryRows, footer: 요약 칼럼, 요약 행, 푸터에도 적용할지 여부. 각각 기본값은 false입니다.

Return : 없음

// TOTAL 합계에 행별 히트맵을 적용합니다.
AUIPivot.setVisualAnalytics(myPivotID, [{
    dataField: "TOTAL",
    operation: "SUM",
    heatmap: {scope: "ROW"}
}]);
AUIPivot.updatePivot(myPivotID);

설정 전체를 교체하며 updatePivot 또는 setGridData로 반영합니다. []로 이 API의 설정을 해제해도 기존 useHeatmap 설정은 유지됩니다.

요약 값은 일반 셀과 별도로 비교합니다. 요약 행은 같은 행의 값 필드별, 열 집계 수준별로 비교하며 요약 칼럼과의 교차 셀은 두 옵션이 모두 true여야 합니다. 푸터의 전체 총계 한 셀은 제외합니다. 빈 값은 제외하고 0은 포함하며 사용자 스타일이 우선합니다.

시각화는 화면 전용이며 보고서 정의에 포함되지 않습니다. getVisualAnalytics로 따로 저장합니다. 색상과 막대의 세부 옵션은 시각 분석 안내를 참고하십시오.
