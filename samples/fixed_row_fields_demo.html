원하는 행 칼럼까지 고정하기

fixedRowFieldCount

행 칼럼 고정에서 개수를 선택한 뒤 표를 가로로 스크롤해 보세요. 2개를 선택하면 왼쪽의 판매 지점과 차종은 고정되고 모델부터 움직입니다. 자동은 현재 행 필드 전체를 고정합니다. 

// AUIPivot 2.8부터 사용할 수 있습니다.
const pivotProps = {
    useFixedColumns: true,
    fixedRowFieldCount: 2
};

자동차 판매 자료를 불러오는 중입니다.
