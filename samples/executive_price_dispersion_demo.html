할인, 판매비를 반영한 예상 손익

Report

할인과 판매 비용을 반영한 예상 손익을 차종별로 출력한 보고서입니다.

setDerivedFields 메소드로 기준 매출, 할인액, 판매비와 예상 손익을 차례로 정의합니다. 앞에서 정의한 필드를 다음 계산에 사용할 수 있습니다.

다음 코드는 할인율과 판매비율을 각각 1%로 지정한 예입니다. 원가와 비율은 가정값이며, 기간 또는 지점을 변경하면 기존 필터를 해제합니다. 

// 할인율과 판매비율을 각각 1%로 가정합니다.
AUIPivot.setDerivedFields(myPivotID, [
    {
        // 설정을 적용할 필드 이름입니다.
        dataField: "GROSS_SALES",
        // 화면에서 읽을 표시 이름입니다.
        labelText: "기준 매출",
        // 한 판매 기록에서 계산할 규칙입니다.
        expression: {
            // 두 값을 곱합니다.
            operator: "multiply",
            // 계산에 사용할 두 필드 또는 숫자를 순서대로 넣습니다.
            operands: ["PRICE", "COUNT"]
        }
    },
    {
        dataField: "DISCOUNT_AMOUNT",
        labelText: "추가 할인액",
        expression: {
            operator: "multiply",
            operands: ["GROSS_SALES", 0.01]
        }
    },
    {
        dataField: "NET_SALES",
        labelText: "할인 후 매출",
        expression: {
            // 앞의 값에서 뒤의 값을 뺍니다.
            operator: "subtract",
            operands: ["GROSS_SALES", "DISCOUNT_AMOUNT"]
        }
    },
    {
        dataField: "SELLING_EXPENSE",
        labelText: "판매비",
        expression: {
            operator: "multiply",
            operands: ["NET_SALES", 0.01]
        }
    },
    {
        dataField: "GROSS_PROFIT",
        labelText: "판매비 차감 전 손익",
        expression: {
            operator: "subtract",
            operands: ["NET_SALES", "COST"]
        }
    },
    {
        dataField: "EXPECTED_PROFIT",
        labelText: "예상 손익",
        expression: {
            operator: "subtract",
            operands: ["GROSS_PROFIT", "SELLING_EXPENSE"]
        }
    }
]);

// 차종, 모델 순서로 행을 묶습니다.
AUIPivot.setRowFields(myPivotID, ["NAME", "MODEL"]);

// 값 필드와 집계 연산자 지정하기
AUIPivot.setValueFields(myPivotID, [
    // 판매 대수
    { dataField: "COUNT", operation: "SUM", customLabelText: "판매 대수", formatString: "#,##0" },
    // 기준 매출
    { dataField: "GROSS_SALES", operation: "SUM", customLabelText: "기준 매출", formatString: "#,##0" },
    // 추가 할인액
    { dataField: "DISCOUNT_AMOUNT", operation: "SUM", customLabelText: "추가 할인액", formatString: "#,##0" },
    // 할인 후 매출
    { dataField: "NET_SALES", operation: "SUM", customLabelText: "할인 후 매출", formatString: "#,##0" },
    // 가정 원가
    { dataField: "COST", operation: "SUM", customLabelText: "가정 원가", formatString: "#,##0" },
    // 판매비
    { dataField: "SELLING_EXPENSE", operation: "SUM", customLabelText: "판매비", formatString: "#,##0.00" },
    // 예상 손익
    { dataField: "EXPECTED_PROFIT", operation: "SUM", customLabelText: "예상 손익", formatString: "#,##0.00" },
    // 손익률
    { dataField: "EXPECTED_PROFIT", operation: "RATIO_OF_SUMS", numeratorField: "EXPECTED_PROFIT",
      denominatorField: "NET_SALES", customLabelText: "손익률", formatString: "0.00%" }
]);
