AUIPivot 그리드는 리스트형 JSON 데이터를 다양한 관점에서 분석하여, 요약 정보를 표시 합니다. (100% 클라이언트 사이드 처리)

AUIPivot 을 생성하기 위해서는 일반 JSON 리스트와 피벗 필드(행, 열, 값, 필터)를 구성함으로써 가능합니다.

다음은 반기, 분기, 월 별로 각 지점에서 판매한 자동차 모델의 판매 합계를 분석한 내용입니다.

예를 들어 각 지역에서 가장 인기있는 차종의 색상은 무엇인지 분석해 볼 수 있습니다.

즉, 각 지점에서 판매한 차종[ 행 필드 ]의 색상 별로 [ 열 필드 ] 판매 대수의 합 [ 값 필드 ] 을 피벗팅
