항목을 원하는 순서로 배치하기

enableItemReorder

그랜저 셀에 마우스를 올리면 나타나는 손잡이를 다른 차종의 위나 아래로 끌어 보세요. 손잡이를 누르면 처음, 이전, 다음, 끝으로 이동하는 메뉴도 열립니다. 열 머리글의 색상도 같은 방식으로 옮길 수 있습니다. 

// AUIPivot 2.8부터 사용할 수 있습니다.
const pivotProps = {
    enableItemReorder: true
};

자동차 판매 자료를 불러오는 중입니다.
