피벗 위치와 크기 조절

resize

창의 제목 표시줄을 끌어 이동하고 모서리를 끌어 크기를 변경해 보세요.

이 데모의 이동과 크기 조절은 jQuery와 jQuery UI Dialog를 사용합니다. 두 라이브러리를 먼저 불러오세요.

창 크기가 바뀌면 AUIPivot.resize()에 내용 영역의 너비와 높이를 전달합니다. 데이터와 필드 설정은 유지됩니다. 

// 대화상자의 제목과 안쪽 여백을 제외한 크기를 전달합니다.
const dialog = $("#dialog");
// 피벗을 담는 영역과 피벗 내부의 크기를 함께 맞춥니다.
$("#pivot_wrap").height(dialog.height());
AUIPivot.resize(myPivotID, dialog.width(), dialog.height());
