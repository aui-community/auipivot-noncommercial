분기, 월별 판매 실적과 수익성

Report

분기와 월별 매출액, 판매 대수, 대당 매출과 이익률을 함께 출력한 보고서입니다.

날짜 필드를 등록하고 DATE_QTR, DATE_MONTH를 행 필드에 지정하십시오. RATIO_OF_SUMS 연산자로 대당 매출과 이익률을 계산합니다.

COST는 데모용 가정 원가입니다. 기간 또는 지점을 변경하면 기존 필터를 해제하고 선택한 조건을 적용합니다. 

// 판매일을 등록해 연도, 분기, 월 같은 날짜 항목을 사용할 수 있게 합니다.
AUIPivot.setDateTypeField(myPivotID, "DATE");

AUIPivot.setDerivedFields(myPivotID, [
    // 이익: 판매 기록마다 매출액에서 원가를 뺍니다.
    {
        dataField: "PROFIT", // 새로 사용할 필드 이름
        labelText: "이익", // 화면에 표시할 이름
        expression: {
            operator: "subtract", // 앞의 값에서 뒤의 값을 빼는 계산
            operands: ["TOTAL", "COST"] // TOTAL - COST
        }
    }
]);

// 분기, 월 순서로 행을 묶습니다.
AUIPivot.setRowFields(myPivotID, ["DATE_QTR", "DATE_MONTH"]);

// 값 필드와 집계 연산자 지정하기
AUIPivot.setValueFields(myPivotID, [
    // 매출액
    { dataField: "TOTAL", operation: "SUM", customLabelText: "매출액", formatString: "#,##0" },
    // 판매 대수
    { dataField: "COUNT", operation: "SUM", customLabelText: "판매 대수", formatString: "#,##0" },
    // 대당 매출
    { dataField: "TOTAL", operation: "RATIO_OF_SUMS", customLabelText: "대당 매출", formatString: "#,##0.00",
      numeratorField: "TOTAL", denominatorField: "COUNT" },
    // 이익률
    { dataField: "PROFIT", operation: "RATIO_OF_SUMS", customLabelText: "이익률", formatString: "0.00%",
      numeratorField: "PROFIT", denominatorField: "TOTAL" },
    // 매출 비중
    { dataField: "TOTAL", operation: "GRAND_TOTAL_RATIO", customLabelText: "매출 비중", formatString: "0.00%" }
]);
