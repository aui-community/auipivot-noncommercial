트리, 테이블, 셀병합 전환

setProp / refresh

버튼을 눌러 이미 출력된 보고서를 트리, 테이블, 셀병합 방식으로 바꿉니다. 데이터와 행, 열, 값, 필터 설정은 유지됩니다.

트리는 행 항목을 들여쓰기로 보여 줍니다. 테이블은 각 행 필드를 별도 열로 보여 주고, 셀병합은 같은 항목이 이어지는 셀을 합칩니다.

setProp()으로 layoutType을 바꾼 뒤 refresh()를 호출하면 현재 피벗에 반영됩니다.

// "tree": 트리, "table": 테이블, "tableCellMerge": 셀병합
AUIPivot.setProp(myPivotID, "layoutType", "table");

// 현재 데이터와 피벗 설정을 유지하면서 바뀐 출력 방식을 반영합니다.
AUIPivot.refresh(myPivotID);

자동차 판매 자료를 불러오는 중입니다.
