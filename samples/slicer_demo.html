슬라이서로 좁혀 보는 데이터

createSlicer

슬라이서 삽입 버튼을 누르고 원하는 필드를 선택하면 슬라이서가 만들어집니다.

행에는 차종, 열에는 월을 배치했습니다. 판매 지점과 분기는 어느 영역에도 배치하지 않고 슬라이서로 사용합니다. 이 기능은 2.8.0부터 지원합니다.

AUIPivot.createSlicer(myPivotID)는 필드 선택 창을 엽니다. 확인한 필드마다 이동과 크기 조절이 가능한 슬라이서가 생성됩니다. 닫기 버튼은 해당 필드의 필터를 해제한 뒤 창을 닫습니다. 다른 필드의 필터는 유지합니다.

여러 항목은 복수 선택 버튼 또는 Ctrl(Cmd) 키로 선택합니다. 같은 슬라이서의 선택은 함께 포함하고, 서로 다른 슬라이서의 조건은 모두 만족해야 합니다.

검색은 버튼 목록만 좁히며 흐린 항목은 다른 필터 조건에서 자료가 없는 항목입니다. 제목을 끌어 이동하고 오른쪽 아래 손잡이로 크기를 조절할 수 있습니다. 

// 피벗 생성 속성으로 새 슬라이서의 기본 크기를 지정할 수 있습니다.
const pivotProps = { slicerWidth: 320, slicerHeight: 360 };
// 사용할 필드를 선택한 뒤 확인을 누르면 자동으로 슬라이서를 만듭니다.
AUIPivot.createSlicer(myPivotID);

삽입 슬라이서의 기본 크기는 300×330px입니다. 이 예제는 slicerWidth와 slicerHeight로 320×360px을 지정했습니다.

자동차 판매 자료를 불러오는 중입니다.
