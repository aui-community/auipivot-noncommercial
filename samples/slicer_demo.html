슬라이서로 좁혀 보는 데이터

createSlicer

판매 지점, 차종, 분기를 버튼으로 선택하여 필터링하는 슬라이서 예제입니다.

createSlicer 메소드에 슬라이서를 놓을 영역과 dataField를 지정하십시오. 반환한 ID로 선택값을 설정하거나 해당 필터를 해제할 수 있습니다.

여러 항목은 복수 선택 버튼 또는 Ctrl(Cmd) 키로 선택합니다. 같은 슬라이서의 선택은 함께 포함하고, 서로 다른 슬라이서의 조건은 모두 만족해야 합니다.

검색은 버튼 목록만 좁히며 흐린 항목은 다른 필터 조건에서 자료가 없는 항목입니다. 제목을 끌어 이동하고 오른쪽 아래 손잡이로 크기를 조절할 수 있습니다. 

<div id="region-slicer" style="width:320px; height:280px"></div>

// 판매 지점을 두 열의 버튼으로 표시합니다.
const regionSlicerID = AUIPivot.createSlicer(myPivotID, "#region-slicer", {
    dataField: "REGION",
    columnCount: 2
});

// 서울 지점 선택하기
AUIPivot.setSlicerSelection(myPivotID, regionSlicerID, ["서울 지점"]);

// 이 슬라이서의 필터 해제하기
AUIPivot.setSlicerSelection(myPivotID, regionSlicerID, null);

자동차 판매 자료를 불러오는 중입니다.
