CSV 파일로 내보내기

exportToCsv

AUIPiovt 에서 CSV 데이터로 로컬 PC에 저장합니다.

엑셀로 내보내기에 너무 많은 데이터인 경우 CSV 로 내보내기 하십시오.

	AUIPivot.exportToCsv(myPivotID);


	AUIPivot.exportToCsv(myPivotID, {
		localControl: true, // 로컬 컨트롤 사용
		// 로컬 컨트롤 함수
		localControlFunc: function (data) {
			// 여기서 반환된 Blob 데이터를 개발자가 원하는 방식대로 처리 가능
		}
	});
