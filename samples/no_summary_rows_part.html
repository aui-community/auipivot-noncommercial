필요한 행 부분 합계만 표시

setExceptSumRowFields

layoutType 속성을 "table" 또는 "tableCellMerge" 로 설정한 경우 "요약 행" 을 선택적으로 지정하여 출력한 모습입니다.(부분적으로 요약행 출력하지 않음)

요약 행을 전체 또는 부분적으로 출력하지 않은 경우 속성 showTreeIcon 은 자연적으로 false 처리 됩니다.

참고 : layoutType = "tree" 인 경우 필수로 요약 행이 출력되어야 하므로 setExceptSumRowFields 메소드는 무시됩니다. 

// 행 필드 중 요약 행으로 출력하지 않을 필드 설정
// 즉, 요약행은 REGION, NAME 은 하지 않음. 결과적으로 MODEL에 대한 요약 행만 출력함.
AUIPivot.setExceptSumRowFields(myPivotID, ["REGION", "NAME"]);
