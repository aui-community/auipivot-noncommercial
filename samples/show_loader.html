데이터 처리 중 안내

showInfoMessage
기본적으로 피벗팅 연산을 할 때 로더를 출력 시키지 않습니다.
가벼운 데이터를 피벗팅할 때 사용자에게 불필요한 시각적인 표현이 거슬릴 수 있기 때문입니다.
만약 로더를 출력 하고자 하는 경우 다음처럼 직접 로더를 출력 시키십시오.
또는 부트스트랩 등에서 제공하는 로더를 출력해도 무방합니다.

// 프로세스 로더를 출력 시킴
AUIPivot.showInfoMessage(myPivotID, '<div class="my-process-loader"></div>');
