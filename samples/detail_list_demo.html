getCellDetailList

다음은 각 반기, 분기, 월 별로 요약하여 출력한 보고서입니다.

피벗팅 된 그리드의 특정 셀을 더블 클릭하면, 요약 전의 원본 데이터 중에서 해당 셀의 소스(source)로 사용된 상세 리스트를 확인 할 수 있습니다.

데모 상에선 더블 클릭으로 구성했지만, 다른 이벤트를 받아 상세 리스트 확인 가능합니다.(예: 엔터 키, 클릭 등)

얻어온 상세 리스트(Array)를 개발자 도구의 콘솔에 출력합니다. 이 데이터를 사용 중인 그리드와 연결하십시오.
