항목의 순서를 직접 지정

setCustomValueOrders

판매 지점과 차종을 원하는 순서로 출력한 모습입니다.

setCustomValueOrders()의 values에 실제 항목 값을 원하는 순서대로 작성하십시오. 별도의 정렬 코드 필드를 추가할 필요가 없습니다.

아래 설정은 서울, 부산, 대전 지점을 먼저 표시하고, 각 지점 안에서는 아반테, 소나타, 그랜저 순서로 차종을 표시합니다. 배열에 없는 지점은 기존 순서를 유지하며 뒤에 이어집니다. 

// 지점과 차종의 순서를 각각 지정합니다.
AUIPivot.setCustomValueOrders(myPivotID, [
    {
        dataField: "REGION",
        // 먼저 표시할 지점입니다. 나머지 지점은 뒤에 이어집니다.
        values: ["서울 지점", "부산 지점", "대전 지점"]
    },
    {
        dataField: "NAME",
        // 각 지점 안의 차종 순서입니다.
        values: ["아반테", "소나타", "그랜저", "제너시스", "투싼", "산타페", "스타렉스"]
    }
]);

열의 월은 setDisplayOrderRules()로 오름차순 정렬합니다. 항목 값을 나열하는 setCustomValueOrders()와 함께 사용할 수 있습니다. 

// 피벗 그리드 속성 설정
const pivotProps = {
    // 자동 오름차순 대신 아래 정렬 규칙을 사용합니다.
    displayAutoAscending: false
};

// DATE_MONTH는 setDateTypeField(myPivotID, "DATE")로 생성한 월 필드입니다.
AUIPivot.setDisplayOrderRules(myPivotID, [
    { dataField: "DATE_MONTH", sortType: 1 } // 1월부터 12월까지 오름차순
]);

출력 후 순서를 바꿀 때는 설정한 다음 updatePivot()을 호출하십시오. setCustomValueOrders(myPivotID, [])로 지정한 순서를 해제할 수 있습니다. 표시 순서가 바뀌어도 매출 합계는 같습니다.
