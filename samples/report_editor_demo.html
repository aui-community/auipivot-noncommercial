AUIPivot 2.8

필드 배치부터 수식 입력까지 자동차 판매 보고서를 직접 바꿔 보세요. 아래 단계는 원하는 순서로 선택할 수 있습니다.

원가는 계산 체험용으로 보강한 예시 금액입니다. 이익률은 각 영역의 매출액 합계와 원가 합계로 계산합니다. 숫자 표시 형식은 0.00을 사용합니다.

핵심 설정 보기 
// AUIPivot 2.8부터 사용할 수 있습니다.
const pivotProps = {
    enableGridFieldDrop: true,
    enableItemReorder: true,
    enableCalculatedFieldEditor: true,
    enableFieldSubtotalMenu: true,
    fixedRowFieldCount: 2
};

표 위의 차종을 행에서 열로 끌어 놓으세요. 오른쪽 패널의 색상을 표 위 필터 영역으로 옮길 수도 있습니다.
