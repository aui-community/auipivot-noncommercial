보고서 높이 지정

height

예를 들어 AUIPivot 생성 시 1000* 600 사이즈로 피벗 그리드를 생성한 경우, 피벗팅 할 때 마다 유동적으로 데이터에 따라 높이가 최적화 되어 변경됩니다.(autoGridHeight 속성, 기본값:true)

autoGridHeight 속성을 true 로 설정한 경우 최초의 높이인 600을 초과해서 그리드의 높이가 커지지 않습니다. 이런 경우 수직 스크롤이 생성됩니다.

그러나 피벗팅에 따라 그리드의 높이가 유동적으로 변경되는 것을 원하지 않는다면 autoGridHeight=false 처리 하십시오.
