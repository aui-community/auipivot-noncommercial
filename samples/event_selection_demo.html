선택 변경 이벤트

selectionChange

마우스나 키보드로 다른 셀을 선택해 보세요.

선택이 바뀔 때마다 선택한 셀의 정보를 위쪽 기록에 표시합니다.

bind()는 selectionChange 이벤트가 발생했을 때 실행할 함수를 연결합니다.

선택을 바꿀 때 새 선택 정보가 event로 전달됩니다. 아래 두 번째 예제는 계산이 끝난 뒤 0번째 행과 0번째 열을 선택합니다. 

// 이벤트 등록은 표를 만든 뒤 한 번만 합니다.
AUIPivot.bind(myPivotID, "selectionChange", function (event) {
    console.log(event);
});
// 셀이 생긴 다음 선택해야 하므로 완료 이벤트에서 실행합니다.
AUIPivot.bind(myPivotID, "pivotComplete", function () {
    AUIPivot.setSelectionByIndex(myPivotID, 0, 0);
});
