툴팁 내용 구성

Tooltip

피벗 그리드의 셀에 마우스가 오면 툴팁(Tooltip)을 표시합니다.(showTooltip = true 설정 : 기본값 false임)

피벗 그리드의 툴팁은 보고서에 맞게 동적으로 표시됩니다.(행, 열의 계층 구조와 값을 출력함)

동적으로 출력되는 툴팁 내용을 사용자가 tooltipFunction 으로 임의로 가공하여 출력 시킬 수 있습니다.

데모는 출력 순서를 값, 행, 열 에서 행, 열, 값으로 바꾸고, 행, 열 계층 구조를 " - " 대신 ", " 로 바꿔 출력 시켰습니다.
