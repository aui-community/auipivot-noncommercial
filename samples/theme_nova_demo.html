보고서에 맞는 테마 선택

Theme

표와 필드 패널의 색상 테마를 바꾸어 봅니다.

위쪽에서 Nova 테마를 고르면 다크 모드와 강조 색상도 선택할 수 있습니다. 표의 숫자와 설정은 유지됩니다.

테마는 표의 CSS 파일로 선택합니다. Nova는 CSS 변수와 문서 속성으로 색과 밝기를 바꿀 수 있습니다.

아래 HTML은 Nova 스타일 한 개를 불러옵니다. --aui-accent는 강조색이며 data-aui-theme="dark"는 다크 모드입니다. 속성을 제거하면 밝은 모드로 돌아갑니다. 피벗을 다시 계산할 필요는 없습니다. 

<link rel="stylesheet" href="../AUIPivot/AUIPivot_nova_style.css">
:root { --aui-accent: #0ea5e9; }
// Nova를 불러온 상태에서 다크 모드를 켭니다.
document.documentElement.setAttribute("data-aui-theme", "dark");
// 밝은 모드로 돌아갈 때 실행합니다.
// document.documentElement.removeAttribute("data-aui-theme");
