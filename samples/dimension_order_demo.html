정렬 코드로 행과 열 정렬

setDisplayOrderRules

원본 데이터(source data)에 정렬을 지시하는 필드가 존재할 때 원하는 순서로 정렬을 시켜 보고서에 최종 출력 할 수 있습니다.

선행 속성으로 자동 오름차순으로 출력되는 방식을 해제(displayAutoAscending=false) 한 후 다음처럼 정렬 규칙을 정하십시오. 

// 피벗팅하여 출력 규칙 정하기
// 다음의 규칙은 개별 규칙이 아닙니다. 종합적인 규칙입니다.(다중 키 정렬)
AUIPivot.setDisplayOrderRules(myPivotID, [
		{ dataField : "REGION_CODE", sortType : -1 }, // 판매지점 코드로 내림차순
		{ dataField : "NAME_CODE", sortType : 1 }, // 차종으로 오름차순
		{ dataField : "DATE_MONTH", sortType : -1 } // 월로 내림차순
]);

만약 원본 데이터(source data)에 보고서에는 출력하지 않지만, 출력 순서를 나타내는 "코드(code)"와 같은 필드가 존재한다면 해당 필드를 이용하여 정렬 규칙을 정할 수 있습니다.
