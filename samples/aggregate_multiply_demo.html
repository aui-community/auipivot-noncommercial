기록별 값을 모두 곱하기

MULTIPLY

각 판매 기록의 판매 대수를 서로 곱하여 출력한 모습입니다.

판매 대수 필드에 MULTIPLY 연산자를 지정하십시오. 첫 판매일의 16개 값을 곱한 결과는 15,552이며 실제 판매 대수 합계와는 다릅니다. 

// 값 필드와 집계 연산자 지정하기
AUIPivot.setValueFields(myPivotID, [
    // 판매 대수 값의 곱
    { dataField: "COUNT", operation: "MULTIPLY", customLabelText: "판매 대수 값의 곱", formatString: "#,##0" },
    // 판매 대수 합
    { dataField: "COUNT", operation: "SUM", customLabelText: "판매 대수 합", formatString: "#,##0" }
]);
