행 차원의 조건부 스타일

setRowDimStyleFunction

속성 layoutType 을 "table" 또는 "tableCellMerge" 설정했을 때 셀 병합된 행 차원 분석 값의 스타일을 원하는 대로 정의한 모습입니다.

행 차원 분석 값들을 가운데 정렬하고 조건을 걸어 REGION 필드에만 다른 스타일을 적용한 모습입니다.

또한 트리 아이콘 출력을 하지 않은 모습입니다.(showTreeIcon 속성 false 설정)

	// 행 차원 분석 값(즉, 행 차원 설정 필드 열들) 스타일 지정하기
	AUIPivot.setRowDimStyleFunction(myPivotID, function(rowField, columnIndex) {
		if(rowField == "REGION") { // REGION 을 설정한 경우
			return "my-row-dim-red-style";
		}
		return "my-row-dim-style"; // REGION 외의 모든 행 차원 분석 값들
	});
