수식을 입력해 이익률 계산하기

enableCalculatedFieldEditor

오른쪽 패널의 계산 필드를 눌러 이익률을 선택하거나 새 수식을 추가하세요. 계산 방식을 집계 후 수식으로 선택하고 (매출액 - 원가) / 매출액 * 100을 입력한 뒤 미리보기와 적용을 눌러 보세요.

원가는 계산 체험용으로 보강한 예시 금액입니다. 이익률은 각 영역의 매출액 합계와 원가 합계로 계산합니다. 숫자 표시 형식은 0.00을 사용합니다.

핵심 설정 보기 
// 셀, 부분합, 총합계마다 합산한 금액으로 이익률을 계산합니다.
AUIPivot.setFormulaFields(myPivotID, [
    { dataField: "PROFIT_RATE", labelText: "이익률(%)", expression: "([TOTAL] - [COST]) / [TOTAL] * 100" }
]);
// 수식 정의와 별도로 값 영역에 표시할 필드를 지정합니다.
AUIPivot.setValueFields(myPivotID, [
    { dataField: "TOTAL", operation: "SUM", formatString: "#,##0" },
    { dataField: "COST", operation: "SUM", formatString: "#,##0" },
    { dataField: "PROFIT_RATE", calculation: { kind: "formula" }, formatString: "0.00" }
]);

자동차 판매 자료를 불러오는 중입니다.
