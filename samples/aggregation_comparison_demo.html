집계 방식 비교

operation

같은 자료에 여러 집계 연산자를 적용하여 결과를 비교한 모습입니다.

setValueFields 메소드에 계산 항목을 배열로 지정하면 나란히 출력됩니다. 다음은 판매 기록 수, 중복 없는 고객 수, 판매 대수를 비교하는 설정입니다.

비교 항목을 변경하면 평균, 중앙값, 분산과 비율도 확인할 수 있습니다. CUSTOMER_ID는 데모용 가상 고객 번호입니다. 

// 값 필드와 집계 연산자 지정하기
AUIPivot.setValueFields(myPivotID, [
    // 판매기록 수: 값이 있는 기록을 한 건씩 셉니다.
    { dataField: "PRICE", operation: "COUNT", customLabelText: "판매기록 수" },
    // 고유 고객
    { dataField: "CUSTOMER_ID", operation: "DISTINCT_COUNT", customLabelText: "고유 고객" },
    // 판매 대수
    { dataField: "COUNT", operation: "SUM", customLabelText: "판매 대수" }
]);
