필드별 부분합 표시하기

enableFieldSubtotalMenu

오른쪽 패널의 행 영역에서 판매 지점을 누른 뒤 부분합 설정을 여세요. 부분합 표시를 해제하고 적용하면 지점 부분합만 사라집니다. 차종도 별도로 설정할 수 있습니다.

테이블과 셀병합에서 사용할 수 있으며 마지막 행 필드는 대상에서 제외됩니다. 부분합을 숨기면 접기와 펼치기 아이콘도 숨겨집니다. 

// AUIPivot 2.8부터 사용할 수 있습니다.
const pivotProps = {
    layoutType: "tableCellMerge",
    enableFieldSubtotalMenu: true
};

자동차 판매 자료를 불러오는 중입니다.
