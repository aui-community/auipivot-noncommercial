숫자에 더하는 시각적 비교

setVisualAnalytics

월별, 지점별 매출액과 판매 대수를 색상과 막대로 비교한 모습입니다. 매출액이 클수록 파란색이 진해지고, 판매 대수가 많을수록 녹색 막대가 길어집니다.

setVisualAnalytics()는 계산된 셀에 히트맵(heatmap)이나 데이터 막대(dataBar)를 적용합니다. 값 필드에 설정한 dataField와 operation을 지정하십시오. 숫자와 합계는 바뀌지 않습니다. 

AUIPivot.setVisualAnalytics(myPivotID, [
    {
        dataField: "TOTAL", operation: "SUM",
        // 매출액 합계를 흰색부터 파란색까지 표시합니다.
        heatmap: { scope: "GLOBAL", colors: ["#FFFFFF", "#4374D9"] }
    },
    {
        dataField: "COUNT", operation: "SUM",
        // 판매 대수 합계를 녹색 막대로 표시합니다.
        dataBar: { scope: "GLOBAL", color: "#2F9D27" }
    }
]);
// 이미 출력한 보고서에 변경한 설정을 반영합니다.
AUIPivot.updatePivot(myPivotID);

scope는 비교 범위입니다. GLOBAL은 전체 일반 셀, ROW는 같은 행, COLUMN은 같은 열 안에서 비교합니다. 매출액과 판매 대수는 각각 따로 비교하며, 기본 설정에서는 소계와 총계를 제외합니다.

현재 배치에서 ROW는 같은 월의 지점끼리, COLUMN은 같은 지점의 월끼리 비교합니다. 차종을 필터링하면 선택한 자료를 기준으로 색상과 막대를 다시 계산합니다.

summaryRows: true로 요약 행 시각화를 켜면 같은 요약 행의 지점별 합계를 비교합니다. 요약 칼럼과 만나는 셀은 두 옵션을 모두 켰을 때 표시합니다.

setVisualAnalytics(myPivotID, [])를 설정하고 updatePivot()을 호출하면 시각화를 해제할 수 있습니다.
