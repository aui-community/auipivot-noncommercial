실행 및 라이선스 안내

unauthorized hosts for AUIPivot 메시지가 나타나면 다음 항목을 확인하세요.

  • 파일을 직접 열지 말고 웹 서버에 올린 뒤 http:// 또는 https:// 주소로 접속하세요.
  • 정품 라이선스를 사용하는 경우, 허용된 접속 도메인 또는 IP인지 확인하세요.
  • 평가판 라이선스를 사용하는 경우에도 신청한 접속 도메인 또는 IP로 접속하세요.

주요기능

23개
  1. AUIPivot 기본 데모기본적인 AUIPivot 그리드 출력한 모습을 볼 수 있습니다.
  2. 보고서를 직접 편집해 보세요 NEW필드 이동, 항목 순서, 틀 고정, 부분합과 수식을 한 보고서에서 체험할 수 있습니다.
  3. 피벗 필드 패널 사용하기다양한 관점에서 정보를 분석할 수 있게끔 드래그&드랍을 지원하는 필드 패널을 출력시키는 데모입니다.
  4. 필드 별칭(alias) 지정하기필드의 이름을 다른 이름으로 지정하여 직관성을 높일 수 있습니다.
  5. 필드 패널 그룹과 순서 지정하기필드를 그룹으로 묶고 원하는 순서로 표시하며, 그룹을 끌어 여러 필드를 한 번에 배치합니다.
  6. 초기 화면을 피벗팅 하지 않고 준비 시키기초기 화면을 사용자가 원하는 관점에서 분석 할 수 있도록 준비 상태로 출력시킵니다.
  7. 피벗 출력 방식 - 트리(기본값)다수의 행 필드를 끌어 놓으면 기본적으로 트리 형태로 출력됩니다.
  8. 피벗 출력 방식 - 테이블다수의 행 필드를 끌어 놓으면 각각의 행 필드가 독립적인 셀 공간을 차지하여 출력됩니다.
  9. 피벗 출력 방식 - 셀병합다수의 행 필드를 끌어 놓으면 각각의 행 필드가 독립적인 셀 공간을 차지하고 셀 병합 후 출력됩니다.
  10. 요약 상세(Detail) 리스트 보기(Drill-Down)피벗팅 된 데이터를 구성한 원본(source) 데이터를 알 수 있습니다.
  11. 행, 열에 출력되는 정렬 방식 지정하기피벗 분석 완료 후 출력되는 보고서의 행, 열에 출력되는 정렬 방식을 특정 필드 기준으로 출력 할 수 있습니다.
  12. 필드 순서 지정하기피벗 필드 패널에 출력되는 필드 리스트의 순서를 원하는 순서로 지정할 수 있습니다.
  13. 숫자 포맷팅 지정하기값 필드의 숫자를 원하는 포맷 형식으로 지정합니다.(예, 컴마 출력. 소수점 2자리 등)
  14. 날짜 포맷팅 지정하기날짜에 대한 필드를 원하는 포맷 형식으로 지정합니다.(예: 2019년 1월 4일 등)
  15. 히트맵(Heatmap)으로 렌더링피벗팅되어 출력된 셀의 배경을 특정 색상 스펙트럼으로 출력합니다.
  16. 행, 열 데이터 필터링, 단면 슬라이스 하기출력된 보고서에서 행, 열의 데이터를 필터링하고자 할 때 필터 필드를 활용하여 필터링 할 수 있습니다.
  17. 툴팁(Tooltip) 정의하기마우스 오버 시 툴팁을 표시합니다.
  18. 컨텍스트 메뉴마우스 오른쪽 클릭 시 출력되는 컨텍스트 메뉴입니다.
  19. 지원 가능 연산자 보기AUIPivot 에서 분석 가능한 연산자를 모두 볼 수 있습니다.
  20. 엑셀로 내보내기(Export)피벗 보고서를 엑셀(xlsx) 문서로 저장합니다. 엑셀 내보내기 할 때 진행바 표시 기능을 지원합니다.
  21. 다국어(리소스번들)기본적인 한글 메뉴를 영어, 일본어 등으로 바꿔서 AUIPivot 을 표현합니다.
  22. Theme 변경하기피벗 그리드에 다른 스타일이 적용된 CSS를 설정합니다.
  23. 차트 연동하기피벗 그리드에서 셀 클릭 시 해당 행에 대한 값을 Google Charts, Apache Echarts 로 표현합니다.
