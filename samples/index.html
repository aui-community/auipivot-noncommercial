실행 및 라이선스 안내

unauthorized hosts for AUIPivot 메시지가 나타나면 다음 항목을 확인하세요.

  • 파일을 직접 열지 말고 웹 서버에 올린 뒤 http:// 또는 https:// 주소로 접속하세요.
  • 정품 라이선스를 사용하는 경우, 허용된 접속 도메인 또는 IP인지 확인하세요.
  • 평가판 라이선스를 사용하는 경우에도 신청한 접속 도메인 또는 IP로 접속하세요.

주요 기능

AUIPivot 기본 데모

기본적인 AUIPivot 그리드 출력한 모습을 볼 수 있습니다.

피벗 필드 패널 사용하기

다양한 관점에서 정보를 분석할 수 있게끔 드래그&드랍을 지원하는 필드 패널을 출력시키는 데모입니다.

필드 별칭(alias) 지정하기

필드의 이름을 다른 이름으로 지정하여 직관성을 높일 수 있습니다.

필드 패널 그룹과 순서 지정하기

필드를 그룹으로 묶고 원하는 순서로 표시하며, 그룹을 끌어 여러 필드를 한 번에 배치합니다.

초기 화면을 피벗팅 하지 않고 준비 시키기

초기 화면을 사용자가 원하는 관점에서 분석 할 수 있도록 준비 상태로 출력시킵니다.

피벗 출력 방식 - 트리(기본값)

다수의 행 필드를 끌어 놓으면 기본적으로 트리 형태로 출력됩니다.

피벗 출력 방식 - 테이블

다수의 행 필드를 끌어 놓으면 각각의 행 필드가 독립적인 셀 공간을 차지하여 출력됩니다.

피벗 출력 방식 - 셀병합

다수의 행 필드를 끌어 놓으면 각각의 행 필드가 독립적인 셀 공간을 차지하고 셀 병합 후 출력됩니다.

요약 상세(Detail) 리스트 보기(Drill-Down)

피벗팅 된 데이터를 구성한 원본(source) 데이터를 알 수 있습니다.

행, 열에 출력되는 정렬 방식 지정하기

피벗 분석 완료 후 출력되는 보고서의 행, 열에 출력되는 정렬 방식을 특정 필드 기준으로 출력 할 수 있습니다.

필드 순서 지정하기

피벗 필드 패널에 출력되는 필드 리스트의 순서를 원하는 순서로 지정할 수 있습니다.

숫자 포맷팅 지정하기

값 필드의 숫자를 원하는 포맷 형식으로 지정합니다.(예, 컴마 출력. 소수점 2자리 등)

날짜 포맷팅 지정하기

날짜에 대한 필드를 원하는 포맷 형식으로 지정합니다.(예: 2019년 1월 4일 등)

히트맵(Heatmap)으로 렌더링

피벗팅되어 출력된 셀의 배경을 특정 색상 스펙트럼으로 출력합니다.

행, 열 데이터 필터링, 단면 슬라이스 하기

출력된 보고서에서 행, 열의 데이터를 필터링하고자 할 때 필터 필드를 활용하여 필터링 할 수 있습니다.

툴팁(Tooltip) 정의하기

마우스 오버 시 툴팁을 표시합니다.

컨텍스트 메뉴

마우스 오른쪽 클릭 시 출력되는 컨텍스트 메뉴입니다.

지원 가능 연산자 보기

AUIPivot 에서 분석 가능한 연산자를 모두 볼 수 있습니다.

엑셀로 내보내기(Export)

피벗 보고서를 엑셀(xlsx) 문서로 저장합니다. 엑셀 내보내기 할 때 진행바 표시 기능을 지원합니다.

다국어(리소스번들)

기본적인 한글 메뉴를 영어, 일본어 등으로 바꿔서 AUIPivot 을 표현합니다.

Theme 변경하기

피벗 그리드에 다른 스타일이 적용된 CSS를 설정합니다.

차트 연동하기

피벗 그리드에서 셀 클릭 시 해당 행에 대한 값을 Google Charts, Apache Echarts 로 표현합니다.

활용 예제

  • 피벗 그리드 일반
    1. setGridData — 이미 생성된 피벗 그리드에서 피벗 대상 데이터 바꾸기(소스 데이터 변경)
    2. setProp, refresh — 피벗 출력 방식 트리, 테이블, 셀병합 전환
    3. setExceptFields — 피벗팅 대상 필드 제외 시키기
    4. 행(row), 열(column) 헤더에 있는 기본 필터 없이 출력시키기
    5. 고정 칼럼(틀 고정)을 적용하지 않기
    6. 출력 방식-테이블, 셀머지인 경우 트리 아이콘 출력 안하기
    7. resize — Resizable & Movable 피벗 그리드 예제(with JQuery UI)
    8. 피벗팅할 때 그리드 높이(height) 고정시켜 표현하기
    9. destroy, create — 피벗 그리드 제거 및 재생성(동적 제거 및 생성) 하기
    10. createPivotPanel, destroyPivotPanel — 피벗 필드 패널 제거 및 재생성(동적 제거 및 생성) 하기
    11. getFitColumnSizeList, setColumnSizeList — 칼럼 사이즈 조절 및 크기에 맞추기
    12. 피벗 연산 중에 프로세스 로더 출력 시키기
    13. 피벗 보고서 저장하고 재방문 시 복구하기
  • 집계 연산 및 가상 필드, 그룹화
    1. SUM — 매출액과 판매 대수 합계
    2. COUNT — 판매기록 수 세기
    3. DISTINCT_COUNT — 중복 없는 고객 수
    4. AVG — 차량 가격의 산술 평균
    5. MIN — 판매된 차량의 최저 가격
    6. MAX — 판매된 차량의 최고 가격
    7. MULTIPLY — 기록별 값을 모두 곱하기
    8. MEDIAN — 가격의 중앙값
    9. VARIANCE — 가격의 모집단 분산
    10. STD_DEVIATION — 가격의 모집단 표준편차
    11. SAMPLE_VARIANCE — 가격의 표본 분산
    12. SAMPLE_STD_DEVIATION — 가격의 표본 표준편차
    13. RATIO — 같은 열 전체에서 차지하는 매출 비율
    14. ROW_RATIO — 같은 행 전체에서 차지하는 매출 비율
    15. RATIO_OF_SUMS — 두 합계로 판매 단가 구하기
    16. GRAND_TOTAL_RATIO — 전체 매출 대비 비중
    17. GRAND_TOTAL_COUNT_RATIO — 전체 판매기록 대비 비중
    18. setDateTypeField — 판매일을 연도, 반기, 분기, 월로 묶기
    19. setDerivedFields — 매출에서 원가를 뺀 이익 계산하기
    20. setDerivedFields — 차량 가격대를 하나의 차원으로 만들기
    21. setDerivedFields — 이익 계산과 가격대별로 묶어 보기
    22. registerCustomAggregator — 중복 고객을 고려한 고객당 평균 매출
    23. registerCustomAggregator — 판매 대수를 반영한 평균 가격
    24. registerCustomAggregator — 기준 가격 이상 차량의 판매 비중
    25. setDisplayOrderRules — 판매 지점, 차종, 월을 정렬 코드로 정렬하기
    26. setCustomValueOrders — 지점, 차종의 항목 순서 직접 지정하기
    27. setVisualAnalytics — 히트맵과 데이터 막대로 판매 실적 비교하기
    28. 비교하기 — 판매기록으로 집계 차이 살펴보기
    29. 월별 매출의 열, 행, 전체 비율 한 화면 비교
    30. 경영 보고 1. 지점별 매출, 수익성 진단
    31. 경영 보고 2. 분기, 월별 판매 실적과 수익성
    32. 경영 보고 3. 가격대, 차종별 판매 포트폴리오
    33. 경영 보고 4. 고객별 매출 집중도와 거래 폭
    34. 경영 보고 5. 할인, 판매비를 반영한 예상 손익
  • 부분 합계, 전체 합계 정의
    1. 행(rows) 부분 합계 출력하지 않기
    2. setExceptSumRowFields — 행(rows) 부분 합계 선택적으로 출력하기(일부 제외 시키기)
    3. 열(columns) 부분 합계 출력하지 않기
    4. 행(rows) 전체 합계(Grand Total=Footer) 출력하지 않기
    5. 열(columns) 전체 합계(Grand Total) 출력하지 않기
    6. 열(columns) 부분 합계, 전체 합계 앞에 출력 하기
  • 텍스트 사용자 정의 및 포맷팅
    1. "합계 : 가격" 과 같은 값 필드 명을 원하는 이름으로 바꾸기
    2. 툴팁의 내용을 사용자 정의하기
    3. 피벗 그리드 및 패널의 문구 바꾸기
    4. 공백 또는 NULL 을 0으로 채우기
    5. setRowFormatString — 행 차원에 숫자 필드 넣고 컴마 출력 시키기
  • 엑셀, CSV, PDF 로 내보내기(Export)
    1. exportToXlsx — 상단과 하단에 타이틀 및 추가 텍스트 넣기
    2. exportToXlsx — 엑셀 파일명 및 시트 이름 설정하기
    3. exportToXlsx — 엑셀 로컬 다운로드 or Blob 데이터 얻어 컨트롤 하기
    4. exportToCsv — CSV 로 내보내기
    5. exportToPdf — PDF 로 내보내기
  • 스타일(Style) 재정의
    1. 행의 가로선 출력 및 행 색상 지정하기
    2. setRowDimStyleFunction — 행 차원의 분석 값 스타일 지정하기(예:색상, 가운데 정렬 등)
  • 이벤트 핸들링
    1. 피벗 업데이트 완료 이벤트 핸들링 하기
    2. 셀, 헤더, 푸터 클릭 이벤트 핸들링 하기
    3. 정렬(sorting) 이벤트 핸들링 하기
