분석에서 필드 제외하기

setExceptFields

원본 데이터의 필드에서 사용자가 피벗팅에 사용할 수 없도록 제외 시킨 모습입니다.

제외 시킨 필드는 "MODEL", "DATE", "PRICE", "COUNT" 입니다.

최고의 솔루션은 서버 사이드에서 JSON 데이터를 작성 할 때 원하지 않는 필드를 작성 하지 않는 것입니다.

그러나 예를 들어 하나의 JSON 데이터를 리스트용 그리드에도 사용하고, 피벗팅에도 사용하는 경우, 이 처럼 제외 시킬 수 있습니다.
