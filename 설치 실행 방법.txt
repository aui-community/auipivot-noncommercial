AUIPivot 사용 방법 및 샘플 실행 방법

--------------------------------------------------------------------------------
1 AUIPivot 사용 방법

- AUIPivotLicense.js, AUIPivot.js, AUIPivot_style.css와 messages/AUIPivot.messages.kr.js 포함
- localhost 또는 127.0.0.1에서 비상업용으로 사용합니다. 사용 조건은 LICENSE를 확인하십시오.
- HTML에 다음과 같이 삽입

```
<!-- AUIPivot 라이센스 파일입니다. 그리드 출력을 위해 꼭 삽입하십시오. -->
<script src="./AUIPivot/AUIPivotLicense.js"></script>
<!-- AUIPivot 라이브러리 메인 JS -->
<script src="./AUIPivot/AUIPivot.js"></script>
<!-- AUIPivot CSS 테마 파일 (원하는 테마로 변경 가능) -->
<link rel="stylesheet" href="./AUIPivot/AUIPivot_style.css" />
<!-- AUIPivot 한국어 메시지 -->
<script src="./AUIPivot/messages/AUIPivot.messages.kr.js"></script>
```

--------------------------------------------------------------------------------
2 폴더 구조

제품 패키지를 압축을 해제하면 다음 디렉토리가 보입니다.
- AUIPivot: AUIPivot 라이브러리와 스타일(css)
- AUIPivot-React: React.js용 서브 컴포넌트
- AUIPivot-Vue: Vue.js용 서브 컴포넌트
- dist: AUIPivot 폴더와 동일한 CDN 배포 자원
- documentation: 공식 문서 (index.html 포함)
- export_server_samples: 서버 내보내기 샘플(PHP, JSP, ASP)
- pdfkit: PDF 출력용 라이브러리
- samples: JavaScript 샘플
- samples-React.js: React 샘플
- samples-React.tsx: React + TypeScript 샘플
- samples-Vue.js: Vue 샘플
- samples-Vue.ts: Vue + TypeScript 샘플

--------------------------------------------------------------------------------
3 일반 JS 샘플 실행 방법

	3.1. 제품 패키지의 압축을 해제한 폴더에서 로컬 웹 서버를 실행합니다. localhost 또는 127.0.0.1로 접속하십시오.
	3.2. /samples 또는 /documentation 폴더의 index.html을 브라우저로 실행합니다.
	3.3. AUIPivot 샘플 기능을 바로 확인하고 테스트할 수 있습니다.

--------------------------------------------------------------------------------
4 Vue, React 샘플 실행 방법

    먼저 공통 AUIPivot 폴더를 각 샘플의 src/static/AUIPivot에 복사합니다.

	4.1. samples-React.js
	   - 프레임워크: React (JSX 기반)
	   - 빌드 도구: Vite
	   - 실행 명령어:
	     npm install && npm run dev
	4.2. samples-Vue.js
	   - 프레임워크: Vue 3 (JS 기반)
	   - 빌드 도구: Vite
	   - 실행 명령어:
	     npm install && npm run dev

	4.3. samples-React.tsx, samples-Vue.ts
	   - TypeScript 샘플이며 aui-pivot@1.0.0 타입 패키지를 사용합니다.
	   - 실행 명령어: npm install && npm run dev
